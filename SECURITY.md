# Security Policy

This repository is a sanitized public case study and must never contain confidential client-delivery material.

## Reporting

If you discover a credential, private key, personal information, confidential dataset, private implementation detail or another disclosure issue, do not reproduce the sensitive value in a public issue or pull request.

Use GitHub private vulnerability reporting when available, or notify the repository owner through an existing private channel.

## Repository boundary

Do not add:

- passwords, tokens, API keys or private keys;
- client-identifying information or private branding;
- account identifiers, billing records or commercial details;
- financial statements, company-level private datasets or source PDFs;
- proprietary ranking/valuation implementation source;
- private repository URLs, logs, screenshots or conversations;
- production hostnames, paths or infrastructure configuration.

All contributions must pass the public-safety workflow before merge.
