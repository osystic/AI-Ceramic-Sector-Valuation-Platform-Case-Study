# Validation Evidence

## Private delivery validation

The confidential source repository includes production-oriented CI that validates:

- tracked-file privacy rules;
- required governance/release documentation;
- obvious secret patterns;
- Python source compilation;
- deterministic ranking regression tests.

The private repository also contains broader regression and acceptance suites covering analytical behavior, multi-year scope, language handling, grounding, rankings, export behavior and production stabilization.

## Public showcase validation

This repository validates:

- required case-study artifacts;
- public-showcase metadata;
- absence of common implementation/data file types;
- absence of likely secrets/contact details;
- disclosure-boundary language;
- independent public history.

## Evidence boundary

The validation described here is engineering and repository evidence.

It does not certify:

- investment performance;
- universal financial-statement accuracy;
- valuation suitability for every company or jurisdiction;
- third-party data completeness;
- client-specific private acceptance metrics.
